① 명암 계단: gradientMap

일반 셰이딩은 밝기 N·L(0~1)을 그대로 씁니다. 툰 셰이딩은 이 값을 몇 개 구간으로 양자화합니다. MeshToonMaterial은 gradientMap이라는 작은 텍스처(예: 가로 3픽셀)를 받아 N·L을 좌표로 써서 색을 찾습니다. NearestFilter로 두면 픽셀 사이가 보간되지 않아 경계가 칼같이 끊깁니다.

const steps = new Uint8Array([60, 160, 255]);           // 어두움 / 중간 / 밝음
const gradientMap = new THREE.DataTexture(steps, 3, 1, THREE.RedFormat);
gradientMap.minFilter = gradientMap.magFilter = THREE.NearestFilter;
const mat = new THREE.MeshToonMaterial({ color: '#ff8a65', gradientMap });

여기에 시선과 노멀이 거의 수직인 가장자리를 밝게 칠하는 림 라이트(1 − N·V를 계단화)를 더하면 애니메이션 느낌이 더 납니다. 이 데모는 onBeforeCompile로 넣었습니다.

② 외곽선 방법 A: 반전 헐 (Inverted Hull)

같은 모양을 노멀 방향으로 조금 부풀려 하나 더 그리되, 뒷면만(side: BackSide) 검게 칠합니다. 앞쪽은 원래 물체가 가리고, 테두리로 삐져나온 부분만 선처럼 보입니다. 게임에서 가장 많이 쓰는 방식이고 아주 쌉니다. 다만 노멀이 면마다 갈라진 각진 모서리(상자)에서는 부풀린 면들이 벌어져 선이 끊깁니다.

③ 외곽선 방법 B: 후처리 엣지 검출

씬을 한 번 그린 뒤 화면 이미지에서 깊이나 노멀이 급격히 바뀌는 픽셀을 찾아(Sobel 필터) 칠합니다. 물체 바깥뿐 아니라 겹친 물체 사이, 접힌 면에도 선이 생기고 모서리 문제도 없습니다. 대신 화면 전체를 한 번 더 처리하는 비용이 들고, 선 두께가 픽셀 단위입니다(15장 포스트프로세싱과 같은 구조입니다).

해볼 것

  • 단계 수를 2로 두면 그림자/빛만 있는 강한 만화풍이 되고, 5 이상이면 점점 일반 셰이딩에 가까워집니다.
  • 반전 헐의 두께를 키우고 상자 모서리를 확대해 보세요. 선이 벌어지는 것이 보입니다. 후처리 방식으로 바꾸면 해결됩니다.
  • "셰이딩 비교"를 일반(Standard)으로 바꾸면 같은 장면이 사실적으로 보입니다.
