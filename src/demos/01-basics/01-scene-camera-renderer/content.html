Three.js로 무언가를 화면에 띄우려면 딱 세 가지가 필요합니다.

요소비유하는 일
Scene무대그릴 물체, 조명, 배경을 담는 상자
Camera관객의 눈어느 위치에서, 어느 방향을, 얼마나 넓게 볼지 결정
WebGLRenderer화가카메라에 비친 씬을 GPU로 계산해서 <canvas> 픽셀로 칠함

무대에 올리는 물체는 보통 Mesh입니다. 메시는 모양(Geometry)과 겉모습(Material)의 조합입니다. MeshStandardMaterial처럼 빛에 반응하는 재질은 조명이 없으면 새까맣게 보이므로 조명도 하나 넣어야 합니다.

const scene = new THREE.Scene();
const camera = new THREE.PerspectiveCamera(50, width / height, 0.1, 100);
camera.position.set(3, 2, 4);

const renderer = new THREE.WebGLRenderer({ canvas, antialias: true });
renderer.setPixelRatio(Math.min(devicePixelRatio, 2));
renderer.setSize(width, height);

const cube = new THREE.Mesh(new THREE.BoxGeometry(), new THREE.MeshStandardMaterial({ color: '#7cf0c5' }));
scene.add(cube, new THREE.DirectionalLight('#fff', 3));

renderer.render(scene, camera); // 한 장 그리기

pixelRatio는 CSS 픽셀 하나에 실제 픽셀을 몇 개 쓸지입니다. 레티나 화면(2~3배)에서 1로 두면 흐릿하고, 3으로 두면 픽셀 수가 9배라 느려집니다. 그래서 보통 최대 2로 제한합니다. 안티앨리어싱은 경계의 계단 현상을 부드럽게 만드는 옵션인데, 렌더러를 만들 때만 정할 수 있습니다.

해볼 것

  • pixelRatio를 0.25까지 내려 보세요. 화면이 모자이크처럼 되고, 왼쪽 위 해상도 표시가 줄어듭니다.
  • 안티앨리어싱을 끄고 큐브 모서리를 확대해 보세요. 계단이 보입니다.
  • 조명을 끄면 Standard 재질은 거의 검게 보입니다. 와이어프레임을 켜면 큐브가 삼각형 12개로 이루어진 것이 보입니다.
